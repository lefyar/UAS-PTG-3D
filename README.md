# UAS Game 3D

A 3D driving game. Steer an accelerating car, collect coins, and avoid obstacles. The project includes a main menu, score system, and vehicle shop.

## Open in Unity

Install Unity **2022.3.62f3** through Unity Hub. Choose **Add project from disk**, select the repository root, and let Unity restore the packages and import the assets.

Open [Scene_MainMenu](Assets/Scenes/Scene_MainMenu.unity) from the Project window. Press **Play** in the Editor.
